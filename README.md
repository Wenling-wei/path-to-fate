# 剩下的牌

**在线试玩：https://wenling-wei.github.io/path-to-fate/**
（网页直接打开，不用下载，不用注册。电脑上体验最好，手机也能玩。）

一个关于人生的卡牌游戏，从 18 岁打到人生的尽头。

这里没有抽牌。你手里的牌只会顺着已有的牌往下长：有文凭才有大厂岗位，有本地关系才有县城的相亲。你能主动做的只有三件事：弃牌、切掉一整条路重来、或者清空手牌移民。每一样都很贵。

它想讨论一件事：人生最难的可能不是起手不好，而是换牌太难。好牌早早打完，烂牌反复发作。

现在是第一个可玩版本，数值没调好，文案和规则都可能有问题，欢迎提意见。

## 玩法介绍

### 1. 开局：发牌不公

选一个出身，起手牌就定了，不能挑。

| 出身 | 起手特点 |
|---|---|
| 一线中产 | 有文凭、有住处、有体面，但家里什么都替你想好了 |
| 县城奋斗 | 有手艺、有本地关系网，但所有牌都长在同一张网上 |
| 小镇做题家 | 有文凭和应试功底，钱紧，现场能力弱 |

想更难可以勾选"逆风发牌"，多带一张家里的旧债。

### 2. 每个回合是两年

每回合依次发生三件事：

1. **结算**：手里的牌带来收入，也要付维持费。
2. **顺势牌**：这条路会递给你最多两张牌，每张只能选接或不接。
3. **你的行动**：弃牌、切牌、移民，或者什么都不做，然后进入下两年。

### 3. 牌从哪来：只沿着脉络长

牌分成十条脉络：家庭、自身、教育、行当、官场、资产、关系网、情感、子女、城市。

每张牌上都写着三样东西：它长自哪张牌、它还会长出什么、它已经错过了几张牌的窗口。

- 有"名校文凭"，才会递来"大厂岗位""校友圈"。
- 有"本地关系网"，才会递来"编制""县城相亲"，也会定期发来"人情债"。
- 很多牌有年龄窗口，过了就再也不会出现。

所以什么都不做，手牌也会自己填满，而且全是同一条路上的牌。

### 4. 你能做的三件事

**弃牌**
弃掉一张牌，长在它上面的牌会一起枯掉。枯掉的牌没有产出，但维持费照付。越早拿到的牌，上面长的东西越多，越难弃。

**切牌**
把一整条脉络全部放弃，可以切的有行当、关系网、情感、城市。代价固定，没有任何办法打折：扣钱、扣体面、加关系债、空白两年。之后只能从这条脉络的最底层重新开始，年纪越大起点越差。

**移民**
需要至少 20 块钱，花掉 18。除了婚姻，所有能弃的牌全部清空。到了另一张牌桌，牌的面值重新算：文凭不那么体面了，手艺更值钱，闲话够不着你，国内才有的牌不再出现。

### 5. 弃不掉的牌

家、学历、孩子、慢性病，这些牌弃不掉也切不走。老家会定期给你发烂牌，比如"家里要用钱"，处理掉以后隔几年还会再来。

### 6. 七个数字

| 数字 | 含义 | 出问题会怎样 |
|---|---|---|
| 负荷 | 手里的牌占用的精力，上限随年龄下降；一张牌拿满 8 年会驾轻就熟，负荷 −1 | 超了就记成身体债 |
| 仓位 | 每张牌占的卡槽不一样：学历 0.1，存款习惯 0.1，房子 0.5，工作 1，婴儿期的孩子 1.5。上限从 6 起，每过一幕 +1 | 超出的部分会变成负荷 |
| 钱 | 现金 | 低于 0 要借钱，掉到 −8 爆仓 |
| 体面 | 别人怎么看你 | 太低时关系和感情线不再有人递牌 |
| 可选性 | 你还剩几条路 | 归零后顺势牌自动替你接下 |
| 身体债 | 透支的身体 | 60 岁前到 10 直接出局 |
| 关系债 | 弃牌切牌欠下的人情 | 影响终局的关系质量 |

### 7. 时代牌

每个人生阶段会翻开一张时代牌，直接改写牌面数值。比如"房价叙事强化"让房子更体面，"优化潮"让大厂岗位贬值，"AI 发牌机启动"之后标准答案型的牌一直贬值、现场型的牌一直升值。

### 8. 孩子

结婚后可能递来"孩子"这张牌，接了就不可逆。孩子会自己长大，有学业、亲密、自主三个数值，受你手里的牌影响：补习班加学业，陪伴加亲密，放手让 TA 折腾加自主。

想全职培养，就得切掉自己的行当。高考结果取决于孩子的学业、你手里的文凭和存款，加一点运气。结算时会告诉你，你发给下一代的是一手什么样的起手牌。

### 官场

拿到"编制"就进了官场，多出一条脉络和两个数字：资历（政绩加关系）和问题。

- **八级官阶**：科员、副科、科长、副处、处长、副厅、厅局级、副部级。资历分别要到 4、9、16、25、36、54、76，够了才会递来升迁。副处以上有年龄线，过了就不会再递来。
- **攒资历**：在岗每回合自然涨一点。扎实干活、笔杆子、挂职锻炼、政绩工程涨政绩；站队、小圈子、给领导当秘书涨关系。
- **走动**：在官场里，行动阶段多一个"走动"按钮，可以花钱直接换官场的牌，每回合最多两次。能换的有送烟酒、送字画、送重礼、党校进修、挂职、秘书、白手套、找人摆平等。
- **花钱补资历**：升迁也能在"走动"里直接换。资历不够，每差 1 点多付 3；过了年龄线，再多付 12 破格提拔。每次都记一笔问题。
- **站队和小圈子**：每回合涨关系，但有小概率靠山倒台，牌没了，关系倒扣。
- **捞钱**：副处起会有人递信封，处长起能批项目。钱按级别翻倍，同时"问题"上涨。不收会被说不合群，扣关系。
- **落马**：只要问题大于 0，每回合都有概率被查，问题越多概率越高，顶栏会显示当前概率。落马后官场的牌全部清空、追缴、体面清零，还有四年什么牌都接不到。
- 可以花钱"找人摆平"抹掉一部分问题，也可以用"白手套"把概率减半。退休后概率减半，但不归零。

### 有钱以后

存款过了一定数目，会开始递来另一种牌，也会遇到另一种事。

- **昂贵的牌**：好车、大平层、圈层、高端医疗、国际学校、家族信托、捐一栋楼。它们很贵，换来大量体面、身体、下一代的优势。
- **熟人投资局**：进了圈层才有。投 15，四年后四成翻倍还多，六成血本无归。
- **情人**：有婚姻、又有钱或有权的人才会遇到。负荷 −2，是全游戏最能减压的牌。每回合 12% 被发现：体面大跌，孩子疏远，一半可能离婚并分走一半存款；在官场的人还会记一笔问题。
- **找上门的事**：存款多了，亲戚会来借钱；生意做大了，可能遇到税务稽查。

### 灰色地带

有些牌带着"灰色"标记。它们来钱快、几乎不占卡槽，但每回合都有一定概率出事，概率写在牌面上。

- **打工的人**：吃回扣、飞单、当枪手、挂证、代购、擦边直播、二房东。
- **做生意的人**：两本账、刷单、阴阳合同、保护伞。
- **缺钱的人**：网贷。只有现金见底时才会递来，立刻到账 8，同时多一张"催收"，要 11 才能还清。
- **有闲钱的人**：放贷、牌局。
- **家里的事**：假离婚（七成省下一大笔，三成假戏真做）、托人递条子（孩子学业 +2）、套医保。
- **拉人头**：每回合 +3，六年后一定暴雷，体面和人情一起赔进去。想脱身只能提前弃掉。
- **买来的文凭**：没有学历的人才会遇到，能敲开几扇门。被查出来时，长在它上面的工作一起没。

出事的后果各不相同：罚款、掉体面、连带丢掉工作或店铺，最重的会进去两年。在官场的人每出一次事，问题 +1。翻到"专项整治"或"反腐风暴"时，出事的概率翻倍。

### 成就

一共 51 个成就，分成牌局、打法、行当、官场、钱、灰色、家七组，其中 8 个是隐藏的。解锁时屏幕下方会提示，开局页和牌桌右上角都能打开成就册。记录只保存在你这台设备的浏览器里。

### 9. 人生阶段与结局

一共八幕，从 18 岁的"开荒"到 74 岁以后的"尽头"。中年父母要人照顾，60 岁前后退休，66 岁以后每回合都可能是最后一回合。

没有"通关"。终局给你一张雷达图和一个结局标签，比如《顺流而下》《漂亮的止损》《切过牌的人》《鸡娃耗尽》《把牌传下去》《两袖清风》《落马》《东窗事发》《常在河边走》《没湿鞋》《老无所依》。还会告诉你，这一局主要输在哪：是结构性的、是别人塞的牌，还是自己不敢弃。

### 10. 新手提示

- 不是每张递来的牌都要接。来者不拒通常在三十多岁就把身体打垮了。
- 盯着负荷。卡片上标了"吸血"的牌，是在净消耗你。
- 弃牌前看一眼"连带枯萎"会带走什么。
- 钱留一点余量，烂牌多半要花钱才能处理掉。

## 想请你提意见的地方

玩一局就够，不用打得好。玩完请挑你有感受的几条说，不用每条都答。

**看不看得懂**
1. 第一次打开，用了多久弄明白该怎么玩？卡在哪一步？
2. 哪些词或数字不明白是什么意思？
3. 卡片上的信息是太多、太少，还是刚好？

**好不好玩**
4. 有没有哪个时刻让你犹豫了很久？是哪张牌？
5. 有没有哪段时间觉得无事可做，只是在点"下一回合"？
6. 一局的长度合适吗？
7. 弃牌、切牌、移民，你各用过吗？没用的话是因为不需要、不敢，还是没注意到？

**像不像真的**
8. 哪张牌或哪段文案让你觉得"对，就是这样"？
9. 哪里让你觉得不真实、太刻薄、或者冒犯？
10. 有没有你觉得人生里很重要、但游戏里完全没有的牌？
11. 你的出身、你走的那条路，游戏对它公平吗？

**结局**
12. 你拿到的结局标签是什么？你认同它对你这局的评价吗？
13. 打完之后，你想再来一局吗？为什么？

**已经知道的问题（不用再提）**
- 数值没有经过真人调试：后期钱偏多，中年现金偏紧，移民之后很容易破产。
- 卡片上写的"/年"其实是每回合，也就是两年。
- 手机上排版比较挤。

如果遇到页面卡住或报错，麻烦截个图，并说一下当时在做什么。

意见可以直接发在群里，也可以在本仓库的 [Issues](https://github.com/Wenling-wei/path-to-fate/issues) 里提。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

牌、时代和出身的数据在 `src/data/` 下的三个 JSON 文件里，规则在 `src/game/engine.ts`。`docs/` 是线上页面的构建产物，由 `npm run build:pages` 生成。
